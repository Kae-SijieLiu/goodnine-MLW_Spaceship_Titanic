# Spaceship Titanic Classification Project

## 1. Project Overview

This project is for the Kaggle Spaceship Titanic binary classification task. The goal is to predict whether each passenger was transported or not.

The implementation includes data preprocessing, feature engineering, TensorFlow Decision Forests model training, CatBoost model training, probability-level model fusion, rule-based postprocessing, threshold-based candidate correction, and final Kaggle submission generation.

The main runnable source code is:

```text
final_submission_code.ipynb
```

The final Kaggle submission file generated by the notebook is:

```text
submission_v10_from_0430_model_flip_all_candidates_threshold_04725_05275_demo.csv
```

## 7. How to Run and Train the Model

Run the notebook from top to bottom.

The notebook contains four main cells:

```text
Cell 1: Data preprocessing and feature engineering
Cell 2: Model training, model fusion, and basic rule-based postprocessing
Cell 3: Threshold-based candidate generation
Cell 4: Final submission generation
```

Run the cells in this order:

```text
Cell 1 -> Cell 2 -> Cell 3 -> Cell 4
```

Do not run Cell 4 before Cell 3, because Cell 4 depends on the `unique_candidates` variable generated in Cell 3.

## 8. Cell Details

### Cell 1: Data Preprocessing and Feature Engineering

This cell loads `train.csv` and `test.csv`, handles missing values, and creates engineered features.

Main feature groups include:

- PassengerId features: `GroupId`, `PassengerNo`, `GroupSize`, `IsAlone`
- Cabin features: `Deck`, `CabinNum`, `Side`
- Family name features: `Surname`, `SurnameSize`, `HasFamilyName`
- Spending features: `TotalSpend`, `LuxurySpend`, `ServiceSpend`, spending ratios, and log-transformed spending features
- Age features: `AgeBin`, `IsChild`, `IsTeen`, `IsAdult`
- Interaction features: `HomePlanet_Destination`, `Deck_Side`, `HomePlanet_Deck`, `CryoSleep_Destination`, `VIP_HomePlanet`, `CryoSleep_NoSpending`
- Cluster feature: `SpendAgeCluster`

Generated files:

```text
train_preprocessed.csv
test_preprocessed.csv
test_postprocess_meta.csv
categorical_cols.json
feature_cols.json
```

### Cell 2: Model Training and Basic Postprocessing

This cell trains two models:

```text
TensorFlow Decision Forests Gradient Boosted Trees
CatBoost Classifier
```

The final test probability is produced using weighted soft voting:

```text
base_probability = 0.93 * TFDF_probability + 0.07 * CatBoost_probability
```

Then a light rule-based postprocessing step is applied using CryoSleep/no-spending patterns, awake-spending patterns, and group-level consistency.

Generated files:

```text
tfdf_model/
catboost_b_model.cbm
model_config.json
postprocess_rule_light_prediction.csv
postprocess_probabilities.csv
```

### Cell 3: Threshold-Based Candidate Generation

This cell selects uncertain samples near the decision boundary.

The probability threshold range is:

```text
0.4725 <= base_probability <= 0.5275
```

Candidate samples are selected using group consistency, CryoSleep and spending behavior, model disagreement, and surname-level consistency.

The selected candidates are stored in memory as:

```text
unique_candidates
```

No extra candidate CSV file is saved.

### Cell 4: Final Submission Generation

This cell flips all selected candidates from Cell 3 and generates the final Kaggle submission file.

The final output file is:

```text
submission_v10_from_0430_model_flip_all_candidates_threshold_04725_05275_demo.csv
```

The output format is:

```text
PassengerId,Transported
```

This file can be uploaded directly to Kaggle.

## 9. Model Details

### TensorFlow Decision Forests

Main parameters:

```text
num_trees = 350
max_depth = 6
shrinkage = 0.045
subsample = 0.85
min_examples = 5
random_seed = 42
```

### CatBoost

Main parameters:

```text
iterations = 700
learning_rate = 0.025
depth = 5
l2_leaf_reg = 5.0
random_strength = 1.5
bagging_temperature = 0.7
random_seed = 42
thread_count = 1
```

### Model Fusion

The model fusion formula is:

```text
final_probability = 0.93 * TFDF_probability + 0.07 * CatBoost_probability
```

After fusion, rule-based postprocessing and threshold-based candidate correction are applied.

## 11. Reproducibility

The notebook uses a fixed random seed:

```python
RANDOM_STATE = 42
```

The seed is applied to Python `random`, NumPy, TensorFlow, scikit-learn train-validation split, KMeans, CatBoost, and TensorFlow Decision Forests.

The code also sets environment variables to reduce randomness:

```text
PYTHONHASHSEED=42
TF_DETERMINISTIC_OPS=1
OMP_NUM_THREADS=1
TF_NUM_INTRAOP_THREADS=1
TF_NUM_INTEROP_THREADS=1
```

CatBoost is also trained with:

```text
random_seed=42
thread_count=1
```

Exact results may still vary slightly across different machines or package versions, especially because TensorFlow, TensorFlow Decision Forests, and CatBoost may have environment-level differences.

For the closest reproduction, use the package versions listed in this README and run all cells in order.
